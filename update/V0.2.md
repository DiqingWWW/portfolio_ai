# V0.2 — Visual Refresh

## 概述

V0.2 是一次视觉层面的全面更新。基于 Google AI Studio 生成的参考设计稿，将项目从冷灰色调（`#f5f5f5` / `#373737`）迁移到暖色奶油画布（`#FAF7F2` / `#1A1A1A`），同时保持当前数据驱动架构完全不变。

## 修改清单

### 新建文件

| 文件 | 说明 |
|------|------|
| `src/config/site.ts` | 站点级元数据常量（header title、watermark、footer 文本） |
| `content/nodes.json` | Canvas 节点位置数据，驱动所有导航按钮和装饰块的布局 |
| `.ai/context.md` | 项目上下文文档 |
| `.ai/decisions.md` | 架构决策日志 |
| `.ai/current-task.md` | 当前任务跟踪 |
| `.ai/changelog.md` | 变更记录 |

### 修改文件

| 文件 | 变更内容 |
|------|----------|
| `src/app/globals.css` | 重写为暖色调调色板，Tailwind v4 `@theme` 设计 tokens（`workspace-bg`、`workspace-text`、`workspace-accent`、`workspace-border` 等） |
| `src/app/layout.tsx` | 添加 `next/font/google`（Inter + JetBrains Mono），更新 theme-color meta 为 `#FAF7F2` |
| `src/app/page.tsx` | 主 canvas 视觉重构：header bar、巨型 watermark、左侧 branding block、右侧 name block、footer bar、chip/pill 风格导航节点（带蓝色圆点指示器）、节点位置改为数据驱动 |
| `src/components/FloatingWindow.tsx` | 窗口 chrome 更新：`WORKSPACE // title` 格式、`PAGE.LOG` 标签、拖拽支持、内容区颜色 token 化 |
| `src/components/MacOSFolder.tsx` | 文件夹视觉升级：亮蓝色（`#2E94E3`）主色调、文件夹标签页、"2026 Edition" 和 "Skills Selector" 装饰 badges、peek document 显示项目列表、GitHub 卡片重设计 |
| `src/components/DesignSystemContent.tsx` | 新增 KPI 统计卡片区域（85%+ Component Reuse / 45%+ Cost Reduction / 0 to 1 In 6 Months），数据驱动 |
| `src/types/content.ts` | 新增类型：`KpiCard`、`NodePositions`。扩展现有接口：`ProfileContent`（branding 字段）、`NavigationContent`（footer 字段）、`DesignTokensContent`（kpiCards） |
| `src/lib/content.ts` | 新增 `nodes` 导入和导出 |
| `content/profile.json` | 新增：`brandingStatement`、`brandingDescription`、`nameDisplay`、`roleDisplay` |
| `content/navigation.json` | 新增：`footerLeft`、`footerCenterLeft`、`footerCenterRight` |
| `content/design-tokens.json` | 新增：`kpiCards` 数组 |

## 架构影响

- **数据层**：无破坏性变更，仅新增字段
- **组件层**：视觉呈现变更，props 接口保持兼容
- **构建配置**：无变更（`next.config.ts`、`vercel.json`、`package.json` 未动）
- **路由结构**：无变更

## Vercel 部署兼容性

✅ 可正常部署。所有改动仅限于 CSS tokens、组件视觉呈现和 JSON 内容数据，不涉及构建配置、路由结构或数据管道。

## 已知问题

无阻塞性问题。border-workspace-border/50 等 opacity modifier 在 Tailwind v4 中表现正常。
